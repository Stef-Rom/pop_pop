Pop Pop — Politique de confidentialité

Dernière mise à jour : 13 novembre 2026

Pop Pop est un jeu gratuit, sans publicité et sans achat. Cette page explique quelles données le jeu utilise et pourquoi.

Données conservées sur votre appareil

Votre progression (pop-corn et bonbons collectés, records, avatars et seaux débloqués, défis, succès, réglages) est enregistrée uniquement sur votre appareil. Elle n'est pas envoyée à un serveur. Vous pouvez l'effacer en supprimant les données de l'application ou du site dans les réglages de votre appareil.

Données envoyées pour le classement en ligne

Le classement est facultatif. Rien n'est envoyé tant que vous n'avez pas enregistré un pseudo dans l'écran « Classement ». Le pseudo n'est pas saisi librement : le jeu le compose à partir de mots imposés (par exemple « Panda Malin 42 »), de sorte qu'il ne peut pas contenir de nom réel. Une fois le pseudo enregistré, le jeu envoie :

  • ce pseudo ;
  • votre meilleur score dans chaque mode de jeu ;
  • le code de groupe, si vous en avez saisi un ;
  • un identifiant aléatoire créé par le jeu sur votre appareil, qui sert seulement à reconnaître vos propres scores ;
  • la date de votre dernier record.

Le pseudo et le score sont visibles par les autres joueurs dans le classement. L'identifiant aléatoire n'est jamais affiché ni communiqué aux autres joueurs.

Le jeu ne demande ni nom, ni adresse e-mail, ni numéro de téléphone, ni position géographique, et n'accède ni à vos contacts ni à vos photos. Le code de groupe est composé uniquement de lettres et de chiffres ; choisissez un code qui ne contient pas d'information personnelle.

Hébergement

Les scores du classement sont hébergés par Supabase, et les fichiers du jeu par GitHub Pages. Comme tout service en ligne, ces hébergeurs peuvent enregistrer des informations techniques de connexion, telles que l'adresse IP, pour assurer le fonctionnement et la sécurité de leurs services. Pop Pop n'utilise pas ces informations.

Ce que le jeu ne fait pas

  • Pas de publicité, pas de traceur publicitaire, pas d'outil de mesure d'audience.
  • Pas de vente ni de partage de données avec des tiers.
  • Pas de création de compte.

Enfants

Pop Pop s'adresse à tous les publics, enfants compris. Le jeu peut être utilisé sans le classement en ligne, et dans ce cas aucune donnée ne quitte l'appareil. Le classement ne permet ni d'écrire un texte libre, ni d'échanger des messages avec d'autres joueurs, et ne recueille aucune information permettant d'identifier un enfant.

Modifier ou supprimer vos données

Vous pouvez tirer un nouveau pseudo à tout moment dans l'écran « Classement ». Pour faire supprimer vos scores du classement, écrivez-nous en indiquant votre pseudo : la suppression est effectuée dans un délai de 30 jours.

Contact

Pour toute question ou demande, ouvrez un message sur la page du projet : github.com/Stef-Rom/pop_pop/issues.
